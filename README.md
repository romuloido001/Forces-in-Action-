# Forces in Action! — Grade 7 Science

An offline-friendly interactive lesson about **Balanced and Unbalanced Forces**. It is designed as a static website and can be published free using GitHub Pages.

## Files
- `index.html` — the interactive lesson and learner activities
- `assets/forces-infographic.jpg` — the supplied lesson infographic
- `assets/examples/` — illustrated examples for pushes, pulls, balanced/unbalanced forces, falling fruit, cars, bicycle braking, inclined planes, rocket launch, a ball, and a sailboat

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **Public** repository (for example, `grade7-forces-lesson`).
2. Extract this ZIP file on your computer.
3. Upload `index.html` and the entire `assets` folder to the repository's main/root branch. Keep the folder structure unchanged.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder, then click **Save**.
7. Wait for GitHub Pages to publish. The website address will appear in the Pages section.

## Learner use
1. Open the published website.
2. Enter the learner's full name, grade/section, and date.
3. Complete the lesson activities and quiz.
4. Click **Download my learning output (.json)** or **Download printable report (.txt)**. The browser saves the file to the learner's Downloads folder. Learners may also use **Print / Save as PDF**.
5. The file is downloaded locally; the website does not send learner information to the teacher or store it on a server. Ask learners to submit the downloaded file using the teacher's approved method.

## Teacher notes
The lesson is organized around the four ILAW elements:
- **Intentions:** objectives and success criteria
- **Learning Experience:** explanations, examples, force-arrow simulator, and four learner activities
- **Assessing Learning:** checks for understanding and a 10-item automatically scored quiz
- **Ways Forward:** remediation, practice, enrichment, and teacher follow-up

The learning objectives and core examples are adapted from the uploaded Grade 7 Science worksheet and infographic. The supplied worksheet does not state an official curriculum competency code. Please verify the exact Grade 7 Science competency and content/performance standards against the current DepEd curriculum guide or your school's applicable Budget of Work before formal classroom adoption.

## Technical notes
- No external libraries, accounts, database, or internet connection are needed after the files are downloaded.
- The lesson works as a static site on GitHub Pages and can also be opened locally by double-clicking `index.html`.
- Learner reports are generated in the browser and are not uploaded or transmitted.
